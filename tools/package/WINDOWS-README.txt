AstraGrid Windows Package

Files:
- astragrid.exe: command-line mission-control kernel
- START-ASTRAGRID.cmd: double-click friendly launcher
- VERIFY-ASTRAGRID.ps1: local executable smoke test
- README.md, SECURITY.md, LICENSE: project documentation

Quick start from PowerShell:

  .\astragrid.exe --version
  .\astragrid.exe --help
  .\astragrid.exe init --mission flood-watch --ledger data\mission.agl

Double-click START-ASTRAGRID.cmd if you want the window to stay open while reading startup guidance.
